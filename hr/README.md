# 마인드 사내 인사 문서

마인드(design@mindpool.kr)의 급여·근무조건을 정하는 규정과, 근태·연차를 실제로
운영하기 위한 관리 도구입니다. 이 저장소의 강의자료와는 별개 내용이며,
필요하면 폴더째 다른 저장소로 옮겨도 됩니다.

**작성 기준** — 상시 근로자 **5인 미만** 사업장 · **연봉제**(12등분 지급) ·
**고정 근무** 09:00–18:00 (휴게 12:00–13:00)

## 문서

| 파일 | 성격 | 용도 |
|---|---|---|
| `마인드_취업규칙.docx` | 규정 원문 | 법적 효력을 갖는 문서. 근로계약서의 근거이며 전 직원에게 주지해야 합니다. |
| `마인드_근태연차_관리대장.xlsx` | 관리 도구 | 출퇴근 기록, 휴가 기록, 연차 자동계산, 월별 집계. |
| `마인드_근무정책_안내서.html` | 직원용 요약 | 취업규칙에서 매일 쓰이는 부분만 뽑은 읽기용 문서. |

세 문서는 서로 맞물려 있습니다. 취업규칙이 기준을 정하고, 관리대장이 그 기준으로
계산하며, 안내서가 그것을 직원에게 설명합니다. **취업규칙의 연차 조항을 바꾸면
나머지 두 개도 함께 고쳐야 합니다.**

확정 전에 읽고 **삭제한 뒤** 사용하세요.

### 5인 미만이라 법적 의무가 아닌데 넣은 조항

취업규칙에 한번 적으면 그때부터 회사의 의무가 됩니다. 부담이 크면 확정 전에 빼세요.
(부속 메모 1절에 삭제 방법이 정리돼 있습니다.)

- 제20조①3호 — 관공서 공휴일·대체공휴일 유급
- 제22조 — 연차유급휴가 (법정 기준과 동일)
- 제24조 — 경조휴가 유급
- 제25조 — 병가 연 10일
- 제36조 — 해고 사유 8호 한정 열거
- 제45조 — 직장 내 괴롭힘 금지 및 조사 절차

## 관리대장 구성

| 시트 | 내용 |
|---|---|
| 사용안내 | 시트 구성 · 연차 계산 기준 · 유의사항 |
| 직원명부 | 사번·성명·입사일 등 기준 데이터. **가장 먼저 채웁니다.** |
| 연차현황 | 발생·이월·사용·잔여 자동계산. 입력 칸은 「이월」 하나뿐 |
| 휴가대장 | 휴가 사용 기록 (연차만 연차현황에 반영) |
| 근태기록 | 일별 출퇴근. 근무시간·연장시간 자동계산 |
| 월별집계 | 조회 월 기준 근무일수·지각·조퇴·결근·연차사용 집계 |
| 코드표 | 드롭다운 원본 |

**연차 계산은 입사일 기준**입니다. 회계연도 기준으로 바꾸려면 취업규칙 제22조제3항과
연차현황 시트 F·G·H열을 함께 고쳐야 하고, 전환 시 직원에게 불리하지 않도록
비례 보전이 필요합니다.

> **월차는 없습니다.** 월차휴가는 2003년 근로기준법 개정으로 폐지됐습니다.
> 흔히 「월차」라고 부르는 것은 입사 1년 미만 직원에게 매월 1일씩 생기는
> 연차(최대 11일)이며, 연차현황 시트가 이를 함께 계산합니다.

## 재생성

문서를 고칠 때는 원본 파일을 직접 수정해도 되고, 생성 스크립트를 고쳐 다시 뽑아도 됩니다.
스크립트를 고치는 쪽이 이력 추적에 유리합니다.

```bash
npm install docx                      # 취업규칙 생성기 의존성
node hr/scripts/build-rules.js        # → hr/마인드_취업규칙.docx

pip install openpyxl                  # 관리대장 생성기 의존성
python3 hr/scripts/build-workbook.py  # → hr/마인드_근태연차_관리대장.xlsx
```

## 검수 상태

- 취업규칙 — OOXML 스키마 검증 통과, LibreOffice 렌더 13쪽 전수 확인
- 관리대장 — 수식 9,481개 재계산 결과 오류 0건
- 관리대장 계산 로직 — 축소판(직원 3명·근태 7건·휴가 7건)으로 손계산과 대조하여
  근속기간·산정기간·발생일수·사용일수·잔여·월별집계 전 항목 일치 확인

## 확정 전에 채워야 할 것

1. 제정일·시행일 (표지 및 부칙)
2. 정식 상호 — 본문은 「마인드」로 표기. 법인이면 「주식회사 마인드」로 통일
3. 부속 검토 메모 페이지 삭제
4. 전 직원 주지 → 열람 가능한 위치에 게시
5. 근로계약서에 "그 밖의 사항은 취업규칙에 따른다" 조항 연결

> 실제 시행 전 노무사 또는 관할 고용노동관서의 검토를 받으시기를 권합니다.
