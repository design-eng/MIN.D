# 마인드 사내 인사 문서

마인드(design@mindpool.kr)의 급여·근무조건을 정하는 규정과, 근태·연차를 실제로
운영하기 위한 관리 도구입니다. 이 저장소의 강의자료와는 별개 내용이며,
필요하면 폴더째 다른 저장소로 옮겨도 됩니다.

**작성 기준** — 상시 근로자 **5인 미만** 사업장 · **연봉제**(12등분 · 당월 말일 지급) ·
**고정 근무** 09:00–18:00 (휴게 12:00–13:00) · **수습 3개월 임금 80%** ·
**가산수당 지급**(연장·야간 50% / 휴일 8시간 초과분 100%)

**회사** 마인드(MIN.D) · 대표 최민숙 · 서울시 양천구 목동동로 293 현대 41타워 1314호
**제정** 2026년 8월 27일 · **시행** 2026년 9월 1일 — 일자는 `scripts/build-rules.js` 상단 `CO` 상수에서 바꿉니다.

### 5인 미만이라 법적 의무가 아닌데 넣은 조항

취업규칙에 한번 적으면 그때부터 회사의 의무가 됩니다. 부담이 크면 확정 전에 빼세요.
(부속 메모 1절에 삭제 방법이 정리돼 있습니다.)

- 제21조② — 연장·야간 50%, 휴일 8시간 초과분 100% 가산수당 (근로계약과 통일)
- 제20조①3호 — 관공서 공휴일·대체공휴일 유급
- 제24조 — 하계휴가 운영규칙 (별도 휴가 없이 연차로 사용)
- 제22조 — 연차유급휴가 (법정 기준과 동일)
- 제25조 — 경조휴가 유급
- 제26조 — 병가 연 10일
- 제37조 — 해고 사유 8호 한정 열거
- 제46조 — 직장 내 괴롭힘 금지 및 조사 절차

### 수습기간 임금 감액(80%)의 요건

「최저임금법」 제5조제2항 및 시행령 제3조에 따라, 아래를 **모두** 갖추어야 적법한
감액입니다. 하나라도 어긋나면 감액 자체가 무효가 되어 차액을 소급 지급해야 합니다.

| 요건 | 내용 |
|---|---|
| 계약기간 | 근로계약기간이 1년 이상. 1년 미만 계약은 수습이어도 감액 불가 |
| 기간 | 수습 시작일부터 3개월 이내. 4개월째부터는 전액 지급 |
| 하한 | 감액 후 금액이 최저임금액의 90% 이상 (최저임금 시급 × 209시간 × 0.9) |
| 명시 | 감액 비율과 기간을 **근로계약서에** 기재. 취업규칙에만 있으면 부족 |
| 직무 | 시행령 제3조상 단순노무업무 종사자는 감액 불가 |

최저임금은 매년 고시로 바뀝니다. 채용 시점의 고시를 반드시 확인하세요.
감액하지 않으려면 제9조제3항을 전액 지급으로 되돌리고 제4항을 삭제하면 됩니다.

### 하계휴가 운영

여름휴가는 법정 휴가가 아닙니다. 제24조는 **별도 휴가를 부여하지 않고 연차로 사용**하도록
운영규칙만 정한 조항이라 추가 비용이 없습니다.

| 항목 | 기준 |
|---|---|
| 기간 | 6월 ~ 9월 중 연차 연속 사용 |
| 희망일 제출 | 매년 6월 30일까지 |
| 동시 부재 | 같은 기간 1명 원칙 |
| 중복 시 | 근속 긴 사원 우선 · 전년도 우선권자는 후순위 |
| 조정 | 납품·발표 예정 주간은 협의 조정 |

별도 유급 하계휴가로 바꾸려면 제24조제3항(연차 차감)을 삭제하고 부여 일수를 명시하세요.
**하계휴가비는 규정에 넣지 않았습니다** — 취업규칙에 지급을 정하면 임금성이 인정되어
매년 지급 의무가 생기고 평균임금에 산입되어 퇴직금이 늘어납니다.

## 업무 프로세스

`마인드_업무프로세스.docx` · `.html`은 **업무 수행 방식**에 관한 기준이고, 취업규칙은
**근로조건**을 정한 문서입니다. 둘은 별개이며, 사원은 취업규칙 제10조(복무의무)에 따라
업무 프로세스를 준수합니다.

두 문서가 맞닿는 지점이 있습니다. 업무 프로세스 8항의 **개인 저장소 사용 금지**는
취업규칙 제15조(비밀유지)와 제39조(퇴직 시 자료 반납)를 실제로 이행할 수 있게 하는
전제입니다. 업무 자료가 개인 클라우드에 있으면 회사가 회수할 수 없습니다.

### 2026-08-29 개정 — 원문 6개 항목에 여섯 가지 보완

| 항목 | 넣은 이유 |
|---|---|
| 3 구두 요청의 문서화 | 전화·회의 요청이 기록에 남지 않아 뒤에 다툼이 생김. **"기록되지 않은 요청은 접수되지 않은 것으로 본다"** 는 문장이 규칙을 작동시킴 |
| 4 수정 요청 관리 | 수정 기준이 한 줄도 없었음. 무한 수정이 스튜디오가 손해 보는 가장 흔한 경로. 단계별 2회 기본 · 회신 시 차수 명기 |
| 5 폴더 체계 | 파일명 규칙만 있고 폴더 규칙이 없어 효과가 반감. `클라이언트/프로젝트/연도/단계`, 단계는 `01_리서치`~`05_아카이브` |
| 6 납품 전 점검 | 1항 「4의 배수」 규칙에 검사 지점이 없었음. 6항목 5분 점검 |
| 7 폰트·이미지 라이선스 | 라이선스 없는 폰트가 납품물에 들어가면 회사 책임 |
| 9 프로젝트 시간 기록 | 견적 근거가 없었음. 관리대장 「프로젝트집계」 시트와 연동 |
| 10 입사 첫 주 | 문서가 다 생겼으니 신규 입사자 확인 순서를 한 장으로 |

원문 5항(일정관리) 문장이 구어체 축약이라 뜻을 유지한 채 문어체로 정리했습니다.
나머지 원문 항목은 내용을 그대로 옮겼습니다.

`.html` 판에는 **파일명 생성기**가 들어 있습니다. 다섯 칸을 채우면 규칙에 맞는
파일명이 조합되고 클립보드로 복사됩니다.

## 연봉조정 운영

취업규칙 제34조가 뼈대를 정하고, 「연봉조정 운영기준」이 평가 항목과 인상률을 정하며,
평가표(xlsx)가 계산하고, 연봉계약서가 결과를 확정합니다. 운영기준은 취업규칙이 아니라
별도 문서라 매년 손볼 수 있습니다.

| 항목 | 기준 |
|---|---|
| 시기 | 입사일 기준 매년 1회 — 연차와 같은 사이클 |
| 적용 | 입사 기념일이 속한 달의 **다음 달 1일** |
| 면담 | 적용일이 속한 달의 전달까지 |
| 평가 | 직무 성과 40 · 직무 역량 30 · 협업과 태도 20 · 기여와 성장 10 |
| 등급 | S 90↑ 8~12% · A 80↑ 5~8% · B 65↑ 3~5% · C 50↑ 0~3% · D 동결 |

### 평가 진행 순서와 서식

| 단계 | 누가 | 서식 | 시기 |
|---|---|---|---|
| 1 자기평가 | 직원 | 자기평가서 | 면담 2주 전까지 제출 |
| 2 회사평가 | 대표 | 회사평가표 | 자기평가서를 받은 뒤 작성. 면담 전까지 비공개 |
| 3 산출 | 대표 | 평가표 xlsx | 점수 입력 → 등급 · 권장 인상률 · 조정 연봉 |
| 4 면담 | 양측 | 면담기록서 | 적용일이 속한 달의 전달까지. 2통 서명 |
| 5 합의 | 양측 | 연봉계약서 | 면담기록서가 「합의」인 경우에만 |
| 6 반영 | 대표 | — | 4대보험 보수월액 변경 신고 · 관리대장 연봉 갱신 |

면담기록서의 **합의 / 미합의 체크란**이 제34조제6항을 실제로 작동시키는 장치입니다.
미합의로 끝나도 기록서에 서명해 남기면, 종전 연봉이 유지된다는 사실과 그것이
불이익 사유가 아니라는 점이 문서로 확인됩니다. 평가 기록은 **3년간 보관**합니다.

**제34조에서 반드시 유지해야 할 두 항**

- **제5항** 사원 동의 없이 연봉을 감액하지 않는다 — 평가표의 「조정 연봉」에도
  `MAX(현 연봉, 산출액)`으로 감액 차단이 걸려 있습니다.
- **제6항** 합의 불성립 시 종전 연봉을 계속 적용하고, 이를 이유로 불이익을 주지 않는다 —
  이 조항이 없으면 협상 결렬 시 처리 근거가 없어 분쟁이 됩니다.

회계연도(1월 1일) 일괄 조정으로 바꾸려면 제34조제1항을 고치고, 입사 6개월 미만자를
다음 회차로 미루는 예외를 함께 두어야 합니다.

## 시행 절차

1. `마인드_취업규칙_검토용.docx`의 부속 메모를 읽고 조항을 확정합니다.
2. 확정 내용을 `scripts/build-rules.js`에 반영하고 두 판을 다시 생성합니다.
3. **배포용**과 시행공지문을 전 직원에게 공유하고, 별지 의견 확인서에 서명을 받습니다.
4. 근로계약서 정정 합의서를 직원별로 작성해 2통씩 보관합니다.
5. 취업규칙을 상시 열람 가능한 위치에 게시하거나 공유합니다.
6. 관리대장 직원명부를 채우고 예시 행을 지웁니다.

기존 근로계약서와의 관계상 **불이익 변경에 해당하는 항목이 없어 과반수 동의는 필요하지 않습니다.**
급여 지급일(말일)과 수습기간 임금(80%)이 기존 계약과 동일하고, 가산수당·경조휴가는
취업규칙이 더 유리하기 때문입니다.

## 재생성

문서를 고칠 때는 원본 파일을 직접 수정해도 되고, 생성 스크립트를 고쳐 다시 뽑아도 됩니다.
스크립트를 고치는 쪽이 이력 추적에 유리합니다.

```bash
npm install docx                      # 취업규칙 생성기 의존성
node hr/scripts/build-rules.js          # → 검토용 (부속 메모 포함)
node hr/scripts/build-rules.js --final  # → 배포용 (메모 제외)
node hr/scripts/build-forms.js          # → 공지문 · 합의서 · 운영기준 · 연봉계약서 · 평가 서식 3종 · 업무프로세스
python3 hr/scripts/build-review.py      # → 마인드_연봉조정_평가표.xlsx

pip install openpyxl                  # 관리대장 생성기 의존성
python3 hr/scripts/build-workbook.py    # → 관리대장 (빈 템플릿)
python3 hr/scripts/seed-employees.py    # → 관리대장에 현재 재직자 입력 · 예시 행 삭제
```
