# Google Drive 폴더 지도

만든 자료를 교수님 Drive의 해당 주차 폴더에 올린다. 폴더 이름 규칙이 과목마다
다르므로 아래를 기준으로 한다. 폴더가 없으면 규칙에 맞춰 새로 만든다.

## 포트폴리오제작
`05_포트폴리오` — `1_ReQESZa30VVwTUcF5M30q2k06NcXEnM`
- 주차 폴더: `{NN}_포트폴리오` (예: `03_포트폴리오`)
- `01_과제` — `1DzovIDPGFkhPcymfO97H8OD4pOEoaQVh`

## 서비스디자인
`02_서비스디자인` — `1kEy66w42-iuWrb3UyPkY6V9INxPLrJK9`
- 주차 폴더: `{N}주_서비스디자인` (1주~15주, 모두 만들어져 있다)
- 3주 — `18bJkQUr1M_9g7Hi19AgzHV-qXkIDuklc`

## 컨셉트와 프로세스 (대학원)
`03_콘셉트와프로세스` — `10x9jhZCUltkRvNeQekDXhlnLIlFDtM2b`
- 하위 폴더 이름 규칙이 아직 정리되지 않았다. 확인 후 적을 것.

## 상위
`01_강의` 아래 과목 폴더들이 있고, `90_아카이브`와 `06_Classroom`이 함께 있다.

## 올릴 때 주의
- Drive 커넥터는 파일 내용을 요청에 통째로 실어 보낸다. pptx 가 커지면 한 번에
  못 올린다. 그래서 `build-week.js` 는 STREAM + compression 으로 저장해
  파일을 3분의 1 이하로 줄여 둔다(글자만 있는 덱 70KB 안팎).
- 도판(PNG)은 32색 팔레트로 저장한다. 흑백 선화라 화질 손실 없이 3분의 1이 된다.
- 업로드할 때 `disableConversionToGoogleType: true` 를 주어 pptx 그대로 둔다.
  (Google 슬라이드로 변환되면 Pretendard 조판이 흐트러진다)
