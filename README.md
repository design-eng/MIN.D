## 수정 방법

내용은 전부 `scripts/build-deck.js` 안에 있습니다. 주차별 내용은 `WEEKS` 배열,
단계 정의는 `PHASES` 배열 한 곳에서 관리되며 주차 상세 슬라이드 15장이 여기서
자동 생성됩니다.

```bash
npm install                      # pptxgenjs
npm run build                    # 개요 덱 재생성
node scripts/build-week.js       # 주차별 덱 전체 재생성
node scripts/build-week.js 2 3   # 특정 주차만 재생성
```

주차별 내용을 고치려면 `scripts/week-content.js`의 `WEEK_CONTENT` 배열만 수정하면 됩니다.
레이아웃은 `build-week.js`가 타입별(`cards3` · `rows` · `compare` · `twocol` ·
`statement` · `steps` · `checklist` · `divider`)로 렌더합니다.

## 기획안과 다르게 처리한 부분

- **Phase–주차 배분**: 기획안 타임라인은 단계별 주차 경계를 명시하지 않아,
  주차별 계획표의 1–8주 / 9–15주 구분에 맞춰 4·4·4·3주로 배분했습니다.
- **시간 배분**: 기획안은 "강의 40% / 실습·크리틱 60%"만 규정하지만, 주차별 원본
  자료는 1주 60/40 · 2주 45/55 · 3주 40/60으로 앞 주차에 강의를 몰아두었습니다.
  주차별 덱은 원본을, 개요 덱은 기획안 값을 따릅니다.
- **"과정 평가 45% + 결과 평가 55%"**: 기획안의 6개 항목 배점(10/20/20/20/25/5)은
  어떻게 나눠도 45:55가 나오지 않습니다(가능한 분할은 50:50 또는 70:30).
  개요 덱은 "6개 항목 · 합계 100%"로, 1주차 덱은 항목을 그대로 묶어
  **과정 35% / 중간 발표 20% / 결과물 45%** 로 표기했습니다. 학과 제출 문서와
  숫자를 맞추려면 이 두 곳을 함께 고쳐야 합니다.
