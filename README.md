# 포트폴리오 제작 · 8주 과정 — 강의자료

대학 · 아카데미용 **포트폴리오 제작 8주 커리큘럼** 강의 덱입니다.
슬라이드 28장 전부에 강의 진행용 스피커 노트가 들어 있습니다.

## 결과물

| 파일 | 설명 |
|---|---|
| `dist/포트폴리오_제작_8주과정_강의자료.pptx` | 강의 덱 (16:9 와이드, 28슬라이드) |
| `scripts/build-deck.js` | 덱 생성기 — 내용·레이아웃 수정은 이 파일에서 |

| # | 섹션 | 내용 |

| 23–28 | **PART 03 평가와 운영** | 평가 루브릭 · 산출물 체크리스트 · 도구와 레퍼런스 · 심화 2주 · 첫 주 과제 |

## 커리큘럼 요약

주 1회 180분(강의 45 · 실습 60 · 크리틱 60 · 랩업 15) × 8주.
매주 산출물을 제출하고 다음 수업에서 크리틱하는 루프를 8회 반복합니다.

| 주차 | 주제 | 제출 산출물 |
|---|---|---|
| 1주 | 포트폴리오의 목적과 목표 설정 | 목표 정의서 1p |
| 2주 | 리서치와 포지셔닝 | 벤치마킹 보드 + 포지셔닝 문장 |
| 3주 | 프로젝트 선정과 전체 구조 설계 | 포트폴리오 목차 · 와이어프레임 |
| 4주 | 케이스 스터디 스토리텔링 | 케이스 스터디 A 텍스트 초안 |
| 5주 | 비주얼 디자인과 레이아웃 | 비주얼 적용된 케이스 스터디 A |
| 6주 | 확장과 포맷 제작 | 전체 초안 v1 (PDF + 웹 링크) |
| 7주 | 크리틱과 리파인 | 수정 반영본 v2 + 수정 계획표 |
| 8주 | 최종 발표와 커리어 연결 | 최종본 · 3분 발표 스크립트 · 이력서 1p |

심화 2주(9–10주)는 선택 과정입니다 — 직무별 심화 리파인, 모의 면접과 실전 지원.

### 평가 루브릭

문제 정의와 리서치 20% · **과정의 논리성 25%** · 결과와 임팩트 20% · 비주얼 완성도 20% · 전달력 15%.
(최종 결과물 70% + 주차별 제출 성실도 20% + 크리틱 참여 10%)

## 수정 방법

내용은 전부 `scripts/build-deck.js` 안에 있습니다. 주차별 내용은 `WEEKS` 배열 한 곳에서
관리되며, 주차 상세 슬라이드 8장이 여기서 자동 생성됩니다.

```bash
npm install          # pptxgenjs
npm run build        # dist/ 에 pptx 재생성
```

### 디자인 토큰

파일 상단에 정의되어 있습니다.

- 색: 잉크 `#14161B`(지배색) · 서피스 `#F4F5F7` · 그래파이트 `#6B7280` · 강조 `#FF4A1C` 하나만
- 폰트: **Pretendard** (큰 순번은 Thin/Light)
- 그리드: 13.333″ × 7.5″, 좌우 마진 0.7″, 콘텐츠 폭 11.933″
- 모티프: 번호 칩(라운드 4pt 사각) + 대형 고스트 넘버. 장식용 컬러 바·타이틀 밑줄은 쓰지 않음

> Pretendard가 설치되지 않은 PC에서 열면 시스템 기본 폰트로 대체됩니다.
> 발표 PC에 Pretendard를 설치해 두는 것을 권장합니다.
